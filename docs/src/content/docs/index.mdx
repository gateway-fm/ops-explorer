## What is it?

The Block Explorer is a self-hosted explorer for any EVM-compatible chain. It indexes
blocks, transactions, accounts, tokens, and logs into PostgreSQL and serves them through
a fast React UI and a rate-limited public REST API. It runs anywhere Docker runs, and
every part of the UI can be whitelabelled without touching code.
